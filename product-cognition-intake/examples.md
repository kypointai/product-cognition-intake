# 认知卡 few-shot 示例

> 供录入助手参考的标准产出样例(v4.3)。均满足判定阈值(基础区 N≥3 且有核心卖点/关键事实),顺序为 `商品名称 → 扩展区 → 基础区`。扩展区与基础区的选填项,运营没给就整行不写;触发式必填(规范 §4 规则 11)命中的字段不能省。

## 例1:皇氏水牛奶(乳品·普通食品)
```
商品名称：皇氏水牛奶
规格参数：钙含量=120毫克/100毫升(营养成分表)
蛋白质=3.6克/100毫升(营养成分表)
净含量=200毫升(包装)
适用年龄：3岁以上
卖点依据：高钙=钙含量；高蛋白=蛋白质
定位：高钙水牛纯牛奶，适合早餐和儿童
核心卖点：高钙；高蛋白；营养早餐
关键事实：每100ml含钙约120mg(营养成分表)；生水牛乳为原料(配料表)
能力：营养早餐(高钙高蛋白)
适用人群：儿童
适用场景：早餐；加餐
推荐关键词：牛奶；水牛奶；早餐；高钙
禁用表达：增强免疫；促进长高；助力长身体
允许表达：适合早餐与家庭日常
需求：早餐想喝点有营养的；想给孩子补钙
用户会问：有没有适合小孩喝的牛奶；高钙牛奶推荐
不适合：过敏原=乳糖；乳糖不耐受人群
差异化：生水牛乳为原料
契合理由：儿童(钙和蛋白质含量高,适合作为孩子日常饮奶)；早餐(高钙高蛋白,适合当早餐饮品)
```

> 普通牛奶不是保健食品:运营若写"功效:高钙、高蛋白",改写进 `核心卖点`,不写 `功效：`。
> 人群只写"儿童":本例运营资料写了儿童;"成人"没依据,不写。资料没提儿童,`适用人群` 整行不写。

## 例2:土鸡蛋(生鲜·只有基础区)
```
商品名称：山林散养土鸡蛋
定位：山林散养土鸡蛋，家庭日常和早餐食材
核心卖点：山林散养；营养早餐食材
关键事实：支持水煮、煎蛋、蒸蛋(说明书)；五谷喂养(商家口述)[推断]
能力：早餐做蛋(支持水煮、煎蛋、蒸蛋)
适用场景：工作日早餐；家庭日常烹饪
推荐关键词：土鸡蛋；早餐；蛋
禁用表达：一定比普通鸡蛋营养更高；养生治病
允许表达：适合作为家庭日常蛋类选择；适合早餐和家庭烹饪
不适合：过敏原=鸡蛋
```

> 运营没给参数、型号等,扩展区整段不写,老格式照样有效。
> 鸡蛋人人能吃,不写 `适用人群`(不写"儿童；成人；中老年")。

## 例4:空气炸锅(家电)
```
商品名称：XX 可视空气炸锅
型号：AF-550
规格参数：容量=5.5升(铭牌)
功率=1500瓦(铭牌)
可视窗口=有(说明书)
操作方式=触屏(说明书)
卖点依据：大容量=容量；随时看火候=可视窗口
定位：5.5升可视空气炸锅，适合3-4口之家
核心卖点：大容量；随时看火候；少油烹饪
关键事实：容量5.5升(铭牌)；额定功率1500W(铭牌)；带可视窗口(说明书)
能力：一次做够全家份(容量5.5升)
适用人群：3-4口之家
适用场景：家庭晚餐；周末做点心
推荐关键词：空气炸锅；可视空气炸锅；大容量炸锅
需求：想少油做炸物；不想频繁拉出锅篮看熟没熟
用户会问：有没有能看到里面的空气炸锅；一家四口用多大的空气炸锅
```

> "3-4口之家"须是说明书/详情写了的;资料没写,不要从 5.5 升自己推。`需求` 两条分别对应卖点"少油烹饪"和事实"带可视窗口"。没给尺寸,就不写"不适合单人小厨房"。

## 例5:保健食品(需资质品类)
```
商品名称：XX 牌钙维生素D软胶囊
规格参数：净含量=60粒(包装)
资质：保健食品注册号=国食健注G20200001(有效期至2030-01-01)
定位：钙维生素D软胶囊，适合中老年补钙
核心卖点：钙和维生素D同补；软胶囊易吞服
关键事实：每粒含钙300mg(包装)；每日1粒(说明书)
适用人群：中老年
功效：补钙
推荐关键词：钙片；补钙；维生素D
禁用表达：治疗骨质疏松；增强免疫
允许表达：适合需要补钙的中老年人
不适合：人群=孕妇；年龄=4岁以下
```

> "中老年"取自保健食品标签的"适宜人群",有依据可写。例中注册号为虚构的示例编号。运营未提供注册号时,照常输出(扩展区不写 `资质：`),但输出前提醒:「该商品属于需资质品类,建议补资质,否则将来可能不被推荐」。

## 例6:保健食品之外的风险提示(酒类·合规三段式)
```
商品名称：波波匠10酱香型白酒
型号：波波匠10
规格参数：酒精度=53%vol(包装)
净含量=500毫升/坛(包装)
香型=酱香型(包装)
定位：53度茅台镇酱香型白酒，500mL双坛装
品牌：波波匠
核心卖点：茅台镇酱香型；53度；双坛礼盒装
关键事实：酒精度53%vol、净含量500mL/坛(包装)；原料为红缨子糯高粱、小麦、赤水河水(配料表)
推荐关键词：酱香型白酒；茅台镇白酒；53度白酒；白酒礼盒
禁用表达：养生保健；壮阳；有益健康；治疗疾病；纯粮不上头
允许表达：53度酱香型白酒，适合宴请与送礼
不适合：人群=未成年人；人群=孕妇；人群=驾车人员
```
> 酒类是**触发式必填**的典型:三人群 + 基线禁用表达,缺一条都不合格。`不适合` 是安全提示,可从"含酒精"推定,不算编造人群。

## 例7:服务/住宿类(可出卡·有明确规格)
```
商品名称：宜尚酒店舒适双床房
规格参数：床型=2张1.2米单人床(标题)
面积=30平方米(标题)
窗户=有窗(标题)
吸烟=可吸烟(标题)
定位：宜尚酒店舒适双床房，30平方米有窗
品牌：宜尚酒店
核心卖点：两张1.2米单人床；30平方米；有窗可吸烟
关键事实：2张1.2米单人床、30平方米、有窗、可吸烟(标题)；入住14:00后、退房12:00前(商家口述)[推断]
推荐关键词：双床房；酒店客房；可吸烟房；宜尚酒店
不适合：人群=对烟味敏感者；人群=携带宠物者
```
> 服务/住宿**能出卡**,前提是有可核实的规格项(床型/面积/窗/吸烟)。有"可吸烟"就必须写 `不适合` 对应人群——这是触发式必填,不是可选项。

## 不出卡:非实物占位 / 虚拟卡券(规范 §5.2)
以下都**不出卡**,但必须输出说明,**不能留空**:
- `积分专属产品`、`激活商城身份 有交易操作问题致电客服专线` → 非实物占位,无商品本体
- `购物卡500面值` → 虚拟卡券,认知卡服务于实物商品推荐

```
资料不足，暂不生成知识卡（商品：购物卡500面值）
缺少：非实物商品（虚拟卡券），无商品本体
请补充：如需录入，请提供具体兑换/提货商品名称、规格与说明
「AI 商品简介」请保持原样，不要粘贴本段。
```
- `光照人康养中心 常规餐-早餐`(只有"每日餐食以餐厅当日供应为准")→ 餐饮无可核实菜品/份量,**不出卡**;若给了菜单+份量+价格,则**可以出卡**。
- `理发/律师` 类:有明确服务项(上门剪发)→ 可出卡;只有"全年顾问权益"无服务范围 → 不出卡。

## 反例:合规闭环失败(规范 §4 规则 12)
```
禁用表达：小分子团水；负电位负氧离子；远红外能量功能
核心卖点：含矿物质和微量元素；水质弱碱性；小分子团水   ← 致命:禁用词又写回卖点
```
应删掉卖点里的「小分子团水」,保留 `含矿物质和微量元素；水质弱碱性`;`弱碱性` 若来自商家口述,pH 数值要标 `[推断]`。

```

关键事实：喝了增强免疫、能长高            ← 违规:超范围功效,应改写/进禁用表达
```

## 反例:依据链越界(规范 §4 规则 10)
```
需求：想吃当季新鲜水果                   ← 红薯不是水果,品类越界;可写"想吃点粗粮"(须资料有依据)
用户会问：冬枣哪款甜                     ← 商品是苹果,平台分类挂在冬枣下也不能这么写
能力：湿水也不易滑                       ← 标题只写了"防滑",加了条件=强度升级;"防滑"只留在核心卖点
契合理由：饭后(佐餐解腻)                 ← 资料没写的效果,不写
差异化：乳固体含量高于普通牛奶           ← 无依据的对比;改写本商品特点或不写
使用建议：洗净即食                       ← 资料没给的吃法,不写(生食可能有安全问题)
```

## 无法追问时(批量 / 表格导入)

```
资料不足，暂不生成知识卡（商品：XX 红薯 5斤装）
缺少：核心卖点、关键事实
请补充：产地、品种、净含量、包装或详情页上的商品介绍等原始资料
「AI 商品简介」请保持原样，不要粘贴本段。
```

```
定位：5.5升可视空气炸锅
核心卖点：大容量
```
