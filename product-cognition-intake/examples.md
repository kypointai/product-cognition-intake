# 认知卡 few-shot 示例

> 供录入助手参考的标准产出样例(v4)。均满足判定阈值(基础区 N≥3 且有核心卖点/关键事实),顺序为 `商品名称 → 扩展区 → 基础区`。扩展区与基础区的选填项,运营没给就整行不写。

## 例1:皇氏水牛奶(乳品·普通食品)
```
商品名称：皇氏水牛奶
规格参数：钙含量=120毫克/100毫升(营养成分表)
蛋白质=3.6克/100毫升(营养成分表)
净含量=200毫升(包装)
适用年龄：3岁以上
卖点依据：高钙=钙含量；高蛋白=蛋白质
定位：高钙水牛纯牛奶，适合早餐和儿童
核心卖点：高钙；高蛋白；营养早餐
关键事实：每100ml含钙约120mg(营养成分表)；生水牛乳为原料(配料表)
能力：营养早餐(高钙高蛋白；便于准备)
适用人群：儿童；成人
适用场景：早餐；加餐
推荐关键词：牛奶；水牛奶；早餐；高钙
禁用表达：增强免疫；促进长高；助力长身体
允许表达：适合早餐与家庭日常
需求：早上没时间做早餐；想给孩子补钙
用户会问：有没有适合小孩喝的牛奶；高钙牛奶推荐
不适合：过敏原=乳糖；乳糖不耐受人群
差异化：水牛奶乳固体含量高于普通牛奶
契合理由：儿童(钙和蛋白质含量高,适合作为孩子日常饮奶)；早餐(开盒即饮省时间)
```

> 普通牛奶不是保健食品:运营若写"功效:高钙、高蛋白",改写进 `核心卖点`,不写 `功效：`。

## 例2:土鸡蛋(生鲜·只有基础区)
```
商品名称：山林散养土鸡蛋
定位：山林散养土鸡蛋，家庭日常和早餐食材
核心卖点：山林散养；营养早餐食材
关键事实：支持水煮、煎蛋、蒸蛋(说明书)；五谷喂养(商家口述)[推断]
能力：快速准备早餐(支持水煮煎蛋蒸蛋)
适用人群：儿童；成人；中老年
适用场景：工作日早餐；家庭日常烹饪
推荐关键词：土鸡蛋；早餐；蛋
禁用表达：一定比普通鸡蛋营养更高；养生治病
允许表达：适合作为家庭日常蛋类选择；适合早餐和家庭烹饪
不适合：过敏原=鸡蛋
```

> 运营没给参数、型号等,扩展区整段不写,老格式照样有效。

关键事实：LR6 碱性电池(包装)；单节1.5V(包装)

适用场景：遥控器；无线鼠标；儿童玩具
推荐关键词：5号电池；碱性电池；AA
禁用表达：续航当事实断言
允许表达：适合日常小电器使用
```

## 例4:空气炸锅(家电)
```
商品名称：XX 可视空气炸锅
型号：AF-550
规格参数：容量=5.5升(铭牌)
功率=1500瓦(铭牌)
可视窗口=有(说明书)
操作方式=触屏(说明书)
卖点依据：大容量=容量；随时看火候=可视窗口
定位：5.5升可视空气炸锅，适合3-4口之家
核心卖点：大容量；随时看火候；少油烹饪
关键事实：容量5.5升(铭牌)；额定功率1500W(铭牌)；带可视窗口(说明书)
能力：一次做够全家份(容量5.5升)
适用人群：3-4口之家
适用场景：家庭晚餐；周末做点心
推荐关键词：空气炸锅；可视空气炸锅；大容量炸锅
需求：想少油做炸物；不想频繁拉出锅篮看熟没熟
用户会问：有没有能看到里面的空气炸锅；一家四口用多大的空气炸锅
不适合：单人小厨房(体积较大)
```

## 例5:保健食品(需资质品类)
```
商品名称：XX 牌钙维生素D软胶囊
规格参数：净含量=60粒(包装)
资质：保健食品注册号=国食健注G20200001(有效期至2030-01-01)
定位：钙维生素D软胶囊，适合中老年补钙
核心卖点：钙和维生素D同补；软胶囊易吞服
关键事实：每粒含钙300mg(包装)；每日1粒(说明书)
适用人群：中老年
功效：补钙
推荐关键词：钙片；补钙；维生素D
禁用表达：治疗骨质疏松；增强免疫
允许表达：适合需要补钙的中老年人
不适合：人群=孕妇；年龄=4岁以下
```

> 例中注册号为虚构的示例编号。运营未提供注册号时,照常输出(扩展区不写 `资质：`),但输出前提醒:「该商品属于需资质品类,建议补资质,否则将来可能不被推荐」。

## 拒绝录入(禁售品)
运营要录入「XX 感冒灵颗粒(OTC)」→ 命中药品,回复:「该类商品不进入 AI 导购,不输出知识卡。」

## 反例(不该这么写)
```

类目：小家电；厨房电器                   ← v4 已下线,不写
核心卖点：最好的牛奶；国家级品质          ← 违规:绝对化用语,应拒绝
关键事实：喝了增强免疫、能长高            ← 违规:超范围功效,应改写/进禁用表达
关键事实：容量5.5升(网上看的)            ← 来源不在固定列表,应问运营实际出处
规格参数：容量=5500毫升                  ← 漏写来源;且运营给的是 5.5升就照写,不换算
```
```
定位：5.5升可视空气炸锅
核心卖点：大容量
型号：AF-550                            ← 扩展区放到了基础区后面,会被并进"核心卖点",应移到商品名称下面
